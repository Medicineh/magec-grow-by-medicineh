✈️ Guía de Telegram - Magec Grow

Para recibir alertas climáticas en tu móvil, necesitas configurar un Bot de Telegram. Es un proceso gratuito que solo lleva 2 minutos.

1. Crear un Bot de Telegram

1. Busca a @BotFather en Telegram.

2. Envía el comando /newbot.

3. Sigue las instrucciones para darle un nombre y un usuario a tu bot.

4. Copia el Token API que te proporcionará (ejemplo: 123456:ABC-DEF...).

2. Obtener tu Chat ID

1. Busca a @userinfobot en Telegram.

2. Envía cualquier mensaje.

3. Te responderá con un número (ejemplo: 987654321). Ese es tu Chat ID.

4. Importante: Inicia una conversación con tu propio bot (el que creaste en el paso 1) y pulsa "Iniciar" para que pueda enviarte mensajes.

3. Seguridad del Token

Aviso Legal y Técnico: El Token del Bot se guarda únicamente en el backend de Supabase como variable de entorno.

La aplicación web no almacena ni muestra el token. Desde la interfaz solo necesitas configurar tu Chat ID.

Tu Chat ID se guarda en la sesión del navegador para facilitar la suscripción y pruebas.

4. Probar la Conexión

Una vez introducido tu Chat ID en los ajustes de la App, utiliza el botón de "Probar" para recibir un mensaje de "Hola Mundo" y confirmar que todo está correcto.

5. Configurar umbrales de alerta

En Ajustes → Umbrales de Alerta puedes adaptar cuándo quieres recibir avisos.

La app carga valores recomendados automáticamente según la planta seleccionada.

Qué controla cada umbral:

  1. Viento (km/h): activa aviso cuando puede romper tallos o secar en exceso.
  2. Temp. Máxima (°C): alerta por calor que causa estrés y parada de crecimiento.
  3. Temp. Mínima (°C): alerta por frío nocturno y riesgo de daño.
  4. Índice UV: avisa por radiación intensa (sombra/protección recomendada).
  5. Lluvia (mm): útil para prevenir hongos y ajustar riego.

Consejo: empieza con los valores recomendados y ajusta poco a poco según tu terraza/huerto.
